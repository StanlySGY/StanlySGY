## 👋 关于我

我是 **StanlySGY**，专注于 LLM 网关、OpenAI 兼容 API、模型账号调度和 Agent 开发工作流。

我更关注把不同 AI 服务整理成 **统一、稳定、OpenAI 兼容** 的接口，让它们可以直接接入现有 SDK、客户端、自动化工具和开发者工作流。

```txt
核心方向：
LLM 服务 → OpenAI 兼容 API → 网关 / 代理 / Agent 工具链
```

- 🔌 构建 AI 网关、API Proxy 与统一模型入口
- ⚡ 研究多账号调度、流式输出、Tool Calling 与模型路由
- 🧠 探索 Claude Code、Codex、Gemini、Grok 相关开发工作流
- 🛠 偏好简单、实用、可部署的工具，而不是过度设计的系统
