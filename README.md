## About

我是 **StanlySGY**，专注于 LLM 网关、OpenAI 兼容 API、模型账号调度和 Agent 开发工作流。

我更关注把不同 AI 服务整理成 **统一、稳定、OpenAI 兼容** 的接口，让它们可以直接接入现有 SDK、客户端、自动化工具和自动化工作流。

```txt
LLM Services → OpenAI-Compatible API → Gateway / Proxy / Agent Tooling
```
